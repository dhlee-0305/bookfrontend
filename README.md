# 📚 내 서재 (Book Frontend)

도서 관리와 Markdown 문서 공유를 위한 웹 서비스입니다. 보유 도서, 독서 기록, 메모, 통계를 관리하고 이미지가 포함된 문서를 게시할 수 있습니다.

---

## 주요 기능

- **도서 관리**: 도서 등록, 조회, 수정, 삭제
- **독서 기록**: 시작일, 종료일, 별점, 감상문 기록
- **메모**: 도서별 메모 및 페이지 번호 관리
- **통계**: 도서 현황 및 독서 통계 시각화
- **문서 게시판**: 카테고리별 목록, 페이지 이동, Markdown 상세 보기, 파일 업로드 기반 등록·수정·삭제
- **문서 이미지**: 이미지 ZIP 첨부, 수정 시 이미지 전체 교체, Markdown 상대 경로 이미지 표시
- **작성자 정보**: 문서 상세에서 작성자 이메일, 등록·수정 일시, 파일 크기 표시
- **인증**: 이메일 기반 회원가입 / 로그인 (세션 쿠키 방식)

```bash

```

## 문서 게시판 사용

상단의 **문서 게시판** 링크로 이동합니다. 목록과 상세는 로그인 없이 조회할 수 있으며, 등록·수정·삭제는 로그인이 필요합니다. 로그인한 사용자는 모든 문서를 수정·삭제할 수 있습니다.

| 경로 | 기능 |
|------|------|
| `/board` | 문서 목록, 카테고리 필터, 10개 단위 페이지 이동 |
| `/board/:id` | Markdown 상세 및 이미지, 작성자 이메일 표시 |
| `/board/new` | 문서 파일 및 이미지 ZIP 등록 |
| `/board/:id/edit` | 문서 파일 교체, 이미지 전체 교체, 카테고리 변경 |

### 문서 등록·수정

- 카테고리는 **AI / 관리 / 설계 / 기타** 중에서 선택합니다.
- 문서는 UTF-8 `.md` 파일 한 개로 업로드하며 최대 **10MB(10,485,760바이트)**입니다. 빈 파일도 허용합니다.
- 원본 파일명이 문서 제목이 됩니다. 파일명은 최대 240 UTF-8 바이트이며, 같은 카테고리에서 중복할 수 없습니다. 경로 문자, 제어 문자, 선행 마침표, 문서명의 끝 공백·마침표와 Windows 예약 파일명은 사용할 수 없습니다.
- 수정 시 Markdown 파일을 생략하면 기존 본문을 유지합니다. 파일명을 바꾸려면 변경된 이름의 파일을 다시 업로드합니다.
- 상세 화면은 제목, 표, 목록, 체크리스트, 코드 블록 등을 지원합니다. 작성자 이메일이 없는 문서는 `정보 없음`으로 표시합니다.

### 이미지 ZIP 첨부

- 등록·수정 시 이미지 ZIP 한 개를 선택적으로 첨부할 수 있습니다. ZIP 파일도 최대 **10MB**이며, Markdown 파일 크기와 별도로 적용됩니다.
- 지원 이미지 확장자: `png`, `jpg`, `jpeg`, `gif`, `webp`, `avif`, `bmp`, `ico`, `svg`.
- 이미지 파일과 하위 폴더를 ZIP 루트에 배치합니다. ZIP 내부에 `image/` 폴더를 별도로 넣으면 경로가 중복됩니다.
- 서버가 압축을 해제하며, 압축 해제 후 전체 크기는 최대 **100MB**, 파일·디렉터리 항목은 합계 **1,000개**입니다.
- 수정 시 ZIP을 첨부하면 **기존 이미지를 모두 삭제하고 새 ZIP으로 전체 교체**합니다. ZIP을 생략하면 기존 이미지를 유지하고, 빈 ZIP을 첨부하면 이미지를 모두 비웁니다. Markdown 교체 없이 이미지만 수정할 수도 있습니다.
- 목록의 **문서 삭제** 버튼에서 확인 후 삭제하면 문서와 첨부 이미지가 함께 삭제됩니다.

ZIP 내부에 `도표/구성.png`가 있다면 Markdown에서 다음과 같이 참조합니다. 한글·공백과 하위 폴더 경로를 지원합니다.

```markdown
![구성도](image/도표/구성.png)
```

### 문서 API 연동

| 메서드 | 경로 | 용도 |
|--------|------|------|
| GET | `/api/mkbrd` | 목록 조회 (`category`, `page`, `limit`) |
| GET | `/api/mkbrd/:id` | 상세 조회 (`content`, `imageBaseUrl`, `authorEmail` 포함) |
| GET | `/api/mkbrd/:id/image/*` | 첨부 이미지 조회 |
| POST | `/api/mkbrd` | 문서 등록 |
| PUT | `/api/mkbrd/:id` | 문서·이미지 교체 또는 카테고리 변경 |
| DELETE | `/api/mkbrd/:id` | 문서·첨부 이미지 삭제 |

등록·수정은 `multipart/form-data`로 `category`, `file`(Markdown), `images`(선택적 ZIP)를 전송합니다. 수정은 변경할 필드만 전송할 수 있으며 삭제에는 첨부 파일을 보내지 않습니다. 브라우저가 multipart boundary를 생성하고 인증에는 세션 쿠키를 사용합니다.

작성자 이메일은 최초 등록 이력의 사용자 ID로 사용자 테이블에서 조회하며, 등록 이력이나 사용자가 없으면 `null`입니다. 상세 뷰어는 `image/` 상대 경로를 `imageBaseUrl` 아래의 이미지 조회 URL로 변환합니다.

## 프로젝트 구조

```
src/
├── api/          # Axios API 호출 모듈
├── components/   # 공통 재사용 컴포넌트
├── constants/    # 상수 정의
├── context/      # 전역 상태 (AuthContext)
├── hooks/        # React Query 커스텀 훅
├── pages/        # 도서·문서 게시판 등 페이지 컴포넌트
└── utils/        # 문서 업로드 검증 및 이미지 경로 처리
```

상세 기능은 [서비스 명세](docs/spec.md), 문서 API의 요청·응답과 서버 운영 규칙은 [문서 게시판 API 규격서](../bookbackend/docs/mkbrd-api.md)를 참고하세요.
